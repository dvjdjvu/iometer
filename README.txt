Recent Windows UI Improvements (2026)
=====================================

- The main window can be resized and maximized. The Topology pane, property
  sheet, and tab pages adjust to the available space. Window size, position,
  maximized state, and the active tab are restored at the next launch.
- The Access Specifications page scales its controls when the window is
  resized.
- Disk Targets and Network Targets panes expand with the window. Their target
  lists are wider so longer disk and network target names are easier to read.
- Global Access Specifications are saved between launches in
  %APPDATA%\Iometer\GlobalAccessSpecifications.icf.
- Results Display settings are saved between launches, including the six
  displayed statistics, results time range, update interval, and last-update
  recording option.
- Test Setup settings are saved between launches, including the test
  description, run time, ramp-up time, results recording mode, disk worker
  count, and cycling options.


Недавние улучшения интерфейса Windows (2026)
===========================================

- Главное окно можно изменять и разворачивать на весь экран. Панель Topology,
  окно вкладок и страницы настроек подстраиваются под доступное пространство.
  При следующем запуске восстанавливаются размер и положение окна, состояние
  развёртывания и выбранная вкладка.
- Элементы страницы Access Specifications масштабируются при изменении размера
  окна.
- Панели Disk Targets и Network Targets растут вместе с окном. Списки Targets
  стали шире, чтобы длинные имена дисков и сетевых целей было легче прочитать.
- Глобальные профили Access Specifications сохраняются между запусками в
  файле %APPDATA%\Iometer\GlobalAccessSpecifications.icf.
- Настройки Results Display сохраняются между запусками: шесть отображаемых
  показателей, временной диапазон результатов, интервал обновления и запись
  результатов последнего обновления.
- Настройки Test Setup сохраняются между запусками: описание теста,
  длительность, время ramp-up, режим записи результатов, число дисковых
  Worker и параметры cycling.
